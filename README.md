# Simprel Notes

Небольшое приложение для заметок на Kotlin, Android 8.0 и новее. Интерфейс в стиле Material Design 3: спокойные поверхности, карточки с радиусом 28dp, тонкая обводка, кнопки с областью нажатия 48dp. Реализован на Android Views с собственными иконками и переключателями; Markdown карточек разбирает Markwon. Сетевые разрешения не нужны.

## Использование

- По умолчанию каждый вход открывает новую заметку и клавиатуру. На Android 12+ системная заставка использует прозрачную иконку и убирается без анимации выхода; Markdown-парсер загружается только при первом показе форматированных карточек. Сам системный стартовый экран остаётся частью Android: убрать время запуска процесса этим нельзя. [Документация SplashScreen](https://developer.android.com/develop/ui/views/launch/splash-screen).
- Текст сохраняется локально при каждом изменении, в том числе до сворачивания. Пустые заметки в файл и список не попадают. Замена файла атомарная.
- Стрелка и системная кнопка «назад» плавно открывают список. При свайпе вправо редактор движется за пальцем отдельным слоем поверх списка. Короткий свайп или движение обратно возвращает редактор на место; достаточно длинный свайп или быстрый взмах открывает список. Вертикальная прокрутка и выделение текста не перехватываются.
- Корзина удаляет текущую заметку, галочка сохраняет её. Для каждой кнопки отдельно в настройках выбирается завершение приложения или анимированный переход к списку. По умолчанию удаление открывает список, а «Готово» закрывает приложение.
- В списке кнопка «+» создаёт заметку. Удерживайте карточку и перемещайте между другими: соседние карточки сдвигаются с анимацией. Порядок сохраняется при отпускании внутри сетки; отменённое перетаскивание возвращает исходный порядок. Перенос на корзину сверху справа удаляет заметку. Удаление и перестановка сохраняют существующие карточки и прокрутку, а не пересоздают экран.
- Нажатие корзины в списке включает и выключает крестики быстрого удаления без пересоздания карточек и сброса прокрутки. В настройках можно включить «Всегда удаление»: тогда крестики видны постоянно, а корзина остаётся целью перетаскивания.
- Шестерёнка открывает настройки: светлая, тёмная, AMOLED или системная тема; системный либо один из четырёх акцентов; три независимых подтверждения удаления; обычный или форматированный Markdown; старт со списка, новой или предыдущей заметки.
- Раскладка: обычная сверху вниз слева направо или снизу вверх справа налево. Во втором режиме новая заметка появляется снизу справа, список изначально открыт снизу, старые заметки просматриваются прокруткой вверх. Ручной порядок сохранён независимо от способа отображения.
- Настройки меняют существующие элементы на месте, включая язык, тему и акцент: страницу не нужно пересоздавать, её прокрутка сохраняется.
- Язык интерфейса: русский, английский или системный. Если основной язык системы не русский и не английский, используется английский. Выбор применяется сразу и сохраняется.
- Стартовый режим применяется при возвращении из фона. Поворот экрана сохраняет текущий экран.
- В форматированном редакторе видны заголовки, жирный и курсивный текст, зачёркивание, код, ссылки, списки и цитаты. Разметка остаётся в сохранённом тексте. Для точного редактирования скрытых символов переключитесь на обычный текст. Это базовый Markdown, без HTML, загрузки изображений и полноценного редактирования таблиц.

## Собрать APK

Отдельный пакет `kotlin-bin` не нужен. Android Gradle Plugin включает поддержку Kotlin и загружает компилятор при первой сборке.

1. Откройте папку проекта в актуальной Android Studio.
2. В **SDK Manager** установите **Android SDK Platform 37 / 37.0** и **Android SDK Build-Tools 36.0.0**, примите лицензии. Требования плагина: [официальная документация AGP 9.3](https://developer.android.com/build/releases/agp-9-3-0-release-notes); настройка платформы: [Android SDK](https://developer.android.com/about/versions/17/setup-sdk).
3. Для Gradle используйте JDK 21 из Android Studio или установленный JDK 21. Нужен интернет для первого скачивания Gradle и зависимостей.
4. В терминале в папке проекта выполните:

   ```sh
   chmod +x gradlew
   ./gradlew :app:exportReleaseApk
   ```

   В Windows: `gradlew.bat :app:exportReleaseApk`.

APK появится в `dist/Simprel-Notes.apk`. Это подписанная сборка версии 1.2 с выключенной отладкой; название приложения на устройстве — **Simprel Notes**. Для установки через USB включите отладку и выполните:

```sh
adb install -r dist/Simprel-Notes.apk
```

Для сборки без Android Studio установите JDK 21 и Android command-line tools, укажите `ANDROID_HOME` или `sdk.dir` в `local.properties`, затем установите SDK:

```sh
sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "platform-tools"
sdkmanager --licenses
./gradlew :app:exportReleaseApk
```

Ключ подписи находится в `.signing/simprel-notes.keystore`, вне каталога сборки. Для совместимости обновления оставлен тот же сертификат, которым подписан предыдущий APK 1.0: новую версию можно устанавливать поверх него, сохраняя заметки. Сохраните резервную копию ключа: он необходим для следующих обновлений. Каталог `.signing` исключён из Git. Для этой существующей подписи пароль по умолчанию `android`; при другом пароле задайте `SIMPREL_STORE_PASSWORD`.

Для сборки в текущем окружении без Android Studio:

```sh
python3 scripts/build-local.py
```

Результат также будет `dist/Simprel-Notes.apk`. Скрипт использует уже установленный SDK и локальный кэш компилятора/зависимостей. На другом компьютере используйте Gradle или сначала подготовьте соответствующий кэш.

## Проверки

В среде разработки Kotlin-код приложения и инструментальных тестов скомпилирован; ресурсы обработаны AAPT2, DEX создан D8, подпись APK проверена `apksigner`. Сборка здесь выполнена через `python3 scripts/build-local.py` из уже имеющегося кэша: среда запрещает сокеты, необходимые Gradle. Этот вспомогательный скрипт рассчитан на локальный кэш автора; обычный способ сборки — Gradle выше.

JVM-тесты выбора языка, непрерывного движения и возврата свайпа, порогов завершения и скорости взмаха, неизменности набора заметок при перестановке и взаимного соответствия координат в обеих раскладках выполнены успешно. Переводы проверены на одинаковый набор ключей; упаковка, отсутствие флага отладки и совпадение сертификата с APK 1.0 проверяются отдельно.

Эмулятора и подключённого телефона в этой среде нет, поэтому запуск интерфейса и инструментальных тестов на Android ещё не проверен. После подключения устройства:

```sh
./gradlew :app:connectedDebugAndroidTest
```

Инструментальные тесты также проверяют сохранение объектов карточек при перестановке и удалении и нижнее выравнивание обратной раскладки. Тесты проверяют сохранение Unicode и переносов строк, отбрасывание пустых заметок, сохранение порядка, удаление, восстановление после прерванной записи и сохранность исходного Markdown при форматировании. Тесты используют отдельный каталог и не трогают пользовательские заметки.

Ручная проверка на телефоне:

1. Запуск → сразу поле и клавиатура; введите текст, сверните и откройте приложение → прежняя заметка есть в списке.
2. Проверьте каждый из трёх стартовых режимов после Home и после полного закрытия.
3. Проверьте стрелку, свайп, системный Back, галочку; поверните телефон во время ввода.
4. Создайте несколько заметок; переставьте удержанием, удалите перетаскиванием и крестиком. Перезапустите и проверьте порядок.
5. По очереди отключите каждое подтверждение и убедитесь, что остальные продолжают работать; проверьте отмену удаления.
6. Проверьте темы, системный акцент, большой системный шрифт, длинную заметку и оба режима Markdown.
7. Переключите RU/EN/системный язык, включая системный язык, отличный от русского/английского. Диалоги и подписи кнопок тоже должны переводиться.
8. В середине длинной заметки проведите вправо: должен открыться список. Вертикальная прокрутка и выделение по удержанию должны продолжать работать.
9. Прокрутите список и включите/выключите корзину: карточки и позиция прокрутки должны сохраниться без моргания. Включите «Всегда удаление», перезапустите приложение и проверьте крестики и настройку подтверждения.

Заметки хранятся только в данных приложения; удаление приложения удалит и заметки.

Изменения 1.2 дополнительно проверить на устройстве:

1. Удалите одну из многих заметок в начале, середине и конце списка: оставшиеся карточки должны плавно занять освободившееся место без моргания страницы.
2. Удерживайте карточку и ведите через несколько соседей; затем отпустите в сетке. Повторите с отпусканием вне сетки: предварительная перестановка должна отмениться. После перезапуска подтвердите сохранённый порядок.
3. Сделайте короткий свайп редактора, верните палец влево, отпустите; затем сделайте длинный и быстрый короткий свайпы. Поле должно следовать пальцу, отменяться или уезжать с анимацией; заметка не должна теряться.
4. Проверьте все четыре сочетания независимых настроек «После удаления» и «После Готово». Отмена подтверждения удаления всегда оставляет редактор открытым.
5. В обратной раскладке проверьте 1, 2, 3 и много заметок: первая позиция — снизу справа, следующая — слева от неё. Перестановка и удаление должны работать в обоих направлениях.
6. Прокрутите настройки и меняйте тему, акцент, стартовый экран и язык: должны сохраняться существующая страница и позиция прокрутки, без вспышки пустого экрана.
